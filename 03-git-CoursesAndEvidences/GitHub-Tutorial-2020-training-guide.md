## Github tutorial 2020 

URL: [Link del Video](https://www.youtube.com/watch?v=iv8rSLsi1xo)


En este video aprendimos lo siguiente:

1. **Introducción (0:00):** Breve explicación sobre qué es GitHub y su utilidad para el control de versiones y colaboración en proyectos.
2. **Acceso a GitHub (0:45):** Cómo crear una cuenta y acceder a la plataforma.
3. **Crear un repositorio (1:23):** Proceso para crear un nuevo repositorio desde la interfaz web de GitHub.
4. **Visualización de la lista de repositorios (2:23):** Cómo navegar y visualizar los repositorios existentes en tu cuenta.
5. **Instalar GitHub Desktop (3:22):** Instalación y configuración de la aplicación GitHub Desktop para gestionar repositorios localmente.
6. **Clonación de un repositorio localmente (3:45):** Cómo clonar un repositorio desde GitHub a tu máquina local.
7. **Confirmar nuevos cambios (5:02):** Proceso para realizar cambios en un repositorio, confirmarlos (commits) y sincronizarlos con GitHub.
8. **Visualización de confirmaciones en GitHub (6:50):** Cómo revisar el historial de confirmaciones (commits) desde la interfaz web.
9. **Salida (7:25):** Conclusión y recomendaciones finales para seguir aprendiendo sobre GitHub.

Este tutorial es para principiantes que desean aprender los conceptos básicos de GitHub y cómo integrarlo en su flujo de trabajo.
