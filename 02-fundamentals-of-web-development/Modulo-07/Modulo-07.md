### Resumen de lo aprendido

El desarrollo web es una habilidad altamente demandada, ya que permite a las empresas crear sitios web que les ayudan a comercializar sus productos y a interactuar con los clientes. Este campo ofrece numerosas oportunidades de crecimiento profesional y permite a los desarrolladores resolver problemas en diversos sectores, como finanzas, electrónica de consumo, fabricación y distribución.

Existen tres roles principales en el desarrollo web: desarrolladores de front-end, back-end y full-stack. Cada uno requiere competencias técnicas específicas, además de habilidades laborales como comunicación y resolución de problemas. Los desarrolladores web son responsables de crear sitios web funcionales y atractivos utilizando lenguajes como HTML, CSS y JavaScript, además de conocer bibliotecas y marcos populares como React, Express y Ruby on Rails.

El trabajo en equipo es esencial en el desarrollo web, ya que diferentes roles colaboran para ejecutar proyectos. Para quienes consideran una carrera en este campo, cualidades como curiosidad, creatividad, capacidad de escucha y habilidades de comunicación son fundamentales.
